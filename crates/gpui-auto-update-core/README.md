# gpui-auto-update-core

Framework-independent update state, capability, feed, verification, policy, and error contracts used by [gpui-auto-update](https://crates.io/crates/gpui-auto-update). It has no GPUI dependency. Most applications should depend on `gpui-auto-update` instead.
