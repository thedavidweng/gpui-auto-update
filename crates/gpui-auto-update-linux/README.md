# gpui-auto-update-linux

Linux backend for [gpui-auto-update](https://crates.io/crates/gpui-auto-update): verified managed-install staging, helper swap, health confirmation, and rollback. Most applications should depend on `gpui-auto-update` instead.

> Pre-release: managed-install detection and verified release staging are
> implemented so far. See
> [docs/linux-managed-install.md](https://github.com/thedavidweng/gpui-auto-update/blob/main/docs/linux-managed-install.md)
> for the marker and archive contracts and the
> [project README](https://github.com/thedavidweng/gpui-auto-update) for status.
