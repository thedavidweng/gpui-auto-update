# gpui-auto-update

Sparkle-quality automatic updates for GPUI: Sparkle on macOS, signed native updates on Windows and Linux, and one observable GPUI API. This is the crate GPUI applications depend on.

> Pre-release: the GPUI facade (observable `Updater` entity, actions, save
> hooks, preview states) is implemented; platform backends are still in
> progress. See the [project README](https://github.com/thedavidweng/gpui-auto-update)
> for status.
